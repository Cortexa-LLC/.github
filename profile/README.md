# Cortexa LLC

AI-native engineering R&D by [Bryan Woodruff](https://github.com/bawoodruff) — building the tools, frameworks, and proving-ground products of agent-driven software development.

## Featured work

- **[ai-pack](https://github.com/Cortexa-LLC/ai-pack)** — a comprehensive multi-agent workflow framework for Claude Code: agent roles (orchestrator, engineer, reviewer), quality gates, structured development workflows, and clean-code standards. [Full documentation →](https://cortexa-llc.github.io/ai-pack/)
- **[mcp](https://github.com/Cortexa-LLC/mcp)** — standalone Model Context Protocol servers in Go: a federated project knowledge graph (KuzuDB, hybrid semantic search, multi-scope monorepo support) and document-to-Markdown conversion.
- **[openphast](https://github.com/Cortexa-LLC/openphast)** — an open-source bridge from Panja/AMX PHAST home-automation hardware to Home Assistant: a reverse-engineered proprietary protocol over raw IPX, a C++20 daemon, an HA custom component, and an offline simulator — built end-to-end with ai-pack agent workflows.
- **[ADSync](https://github.com/Cortexa-LLC/ADSync-releases)** — a free macOS menu-bar app that keeps Active Directory and macOS/keychain passwords in sync.

## Retro-computing toolchain

A modern, maintained toolchain family for classic platforms — because the fundamentals never go out of style:

- **[xasm-plus-plus](https://github.com/Cortexa-LLC/xasm-plus-plus)** — production cross-assembler in modern C++20: single binary supporting 7 vintage CPU architectures (6502 family, 6809, Z80) and 5 classic syntax modes, 1,600+ tests, cross-platform CI with emulator boot validation — built end-to-end with ai-pack agent workflows
- **[sourcerer](https://github.com/Cortexa-LLC/sourcerer)** — modular disassembler for 6502, 6809, and Z80 with pluggable output formatters
